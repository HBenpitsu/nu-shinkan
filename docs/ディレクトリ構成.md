# ディレクトリ構成

## ディレクトリ

リポジトリルートに存在し，かつgitで管理されるディレクトリを以下に説明します．
（存在すれば）カッコ内にそのディレクトリに関連するツールを付します．

- **`apps/` (turborepo):**
  デプロイされる単位（マイクロサービス，アプリケーション）を配置します．
  たとえば，_一般ユーザ向けWebアプリ_, *組織ユーザ管理サービス*などが該当します．
  それぞれの詳細は`apps/*/README.md`を参照してください．
- **`packages/` (turborepo):**
  複数のアプリケーションから再利用されるコードが配置されます．（ユーザ定義パッケージという位置づけでしょう．）
  たとえば，複数のプロジェクトで再利用される設定，再利用されるUIコンポーネントなどを配置します．
  `packages/`配下の詳しい運用方針については，[packages/README.md](../packages/README.md)を参照してください．
- **`docs/`:**
  このドキュメントが設置されているディレクトリです．コードではない文書全般を配置します．(`docs`ディレクトリ自体の構成に関する説明は，docsディレクトリの[README](./README.md)を参照してください．)
- **`templates/`:**
  このディレクトリの配下には，参考のために残されたコードが配置されます．典型的には，フロントエンドサービス，バックエンドサービスのテンプレートがこれに当たります．
- **`scrpits/`:**
  このディレクトリの配下には，ローカル（開発環境）で実行されるスクリプトが配置されます．
  たとえば，テスト用のデータの自動投入スクリプトなどはここに配置されます．
- **`poc/`:**
  技術調査の結果などをすぐに利用できる形で残すためのディレクトリです．特定の技術の使い方を表すためのシンプルなプロジェクトや，コードスニペットからなります．
- **`.agent/`:**
  AIエージェント向けのファイルを配置するディレクトリです．
  skillの配置などはここに行います．
- **`.devcontainer/` (devcontainer):**
  devcontainerに関連するファイルが収められるディレクトリです．
  たとえば，devcontainer.json, (devcontainer用の) Dockerfile, post-create scriptなどはここに配置されます．つまり，開発環境を構成するために必要な要素がここに集まります．
- **`.github/` (github):**
  CI/CDに関するファイルが収められるディレクトリです．
  dependabotの設定ファイル (依存関係を半自動でアップデートするツール)，github actionsなどが配置されます．

## ファイル

リポジトリルートに存在し，かつgitで管理されるファイルを以下に説明します．

- **`AGENT.md`:**
  AIエージェント向けの文書です．AIエージェントはまず最初にこれを読むことが期待されています．
- **`README.md`:**
  このリポジトリを説明する文書です．人間はまず最初にこれを読むことが期待されています．プロダクトの要約や，見るべきドキュメントの案内などを含みます．
- **`package.json`:**
  _リポジトリルートに存在する_`package.json`は，開発環境・CI/CD環境を構築するために必要な依存関係などを定めます．（appごとに必要な依存関係は，`apps/*/package.json`で定めます．）
- **`pnpm-workspace.yaml`**
  ワークスペースの構造を規定したり，pre/build/post install scriptの実行を許可したりするための設定ファイルです．
- **`turbo.json`:**
  turborepoの設定ファイルであり，ビルド・CI/CDの設定に使用されます．

次のファイル/ディレクトリは自動生成されたものであり，基本的に直接編集することはありません．

- .pnpm-store
- .turbo
- node_modules
- .npmrc
- pnpm-lock.yaml
